# P2 - 二期迭代

> 二期迭代目录。一期 MVP 文档见 [../mvp/](../mvp/)。

---

## 1. P2 范围

P2 在 MVP（群聊 + @机器人触发）的基础上迭代飞书接入体验，按主题拆分为独立的子目录，
每个子目录包含自己的 `spec.md`（需求）/ `design.md`（设计）/ `task.md`（任务）。

| 子主题 | 状态 | 说明 |
|---|---|---|
| [emoji-reply](./emoji-reply/) | ✅ 已完成 | 收到消息立即在原消息上打 `OnIt` 表情作为 < 200ms 即时 ack，Run 完成后移除 |
| [direct-chat](./direct-chat/) | 🔵 进行中 | 支持机器人应用的单聊（p2p）触发；任意好友消息自动落到默认 WS |

---

## 2. 阅读顺序

1. 先读 [../mvp/spec.md](../mvp/spec.md) 了解 MVP 基线（群聊 @ 触发、卡片生命周期、D21 无权限模型）
2. 按子主题独立阅读各 `spec → design → task`
3. 子主题之间默认解耦，无强依赖；若产生交集（如 direct-chat 复用 emoji-reply 的 ack 机制），在各自 design 文档中标注

---

## 3. 文档维护约定

- **目录命名**：`p2/<topic>/`，topic 用小写连字符（如 `direct-chat`）
- **新增主题**：在 §1 表格追加一行 + 新建 `<topic>/` 子目录
- **状态流转**：进行中 → 已完成；完成后在表格标注 ✅
- **跨阶段引用**：MVP 文档用 `../../mvp/...`；同 P2 内子主题用 `../<topic>/...`
